Hostel Management System

A modern Hostel Management System developed using **Python**, **Flask**, **SQLite**, and **Bootstrap** to manage hostel operations efficiently.

---

Features

- Dashboard Statistics
- Student Management
- Room Management
- Complaint Management
- Student Search
- Room Occupancy Chart
- Complaint Status Chart
- CSV Export
- PDF Export
- Responsive UI

---

Tech Stack

- Python
- Flask
- SQLite
- SQLAlchemy
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Chart.js
- ReportLab

Installation

```bash
git clone <repository-url>

cd Hostel-Management-System

python3 -m venv venv

source venv/bin/activate

pip install -r requirements.txt

python app.py
```
